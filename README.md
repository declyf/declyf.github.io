# DECLYF

**Coach smarter. Live dedicated.**

DECLYF is a coaching platform for fitness coaches and their clients. Coaches build workout
and nutrition plans; clients log meals, workouts and weight; both sides see the same real numbers.

### Install

**https://declyf.github.io**

- **iPhone** — open the site in Safari, then Share → Add to Home Screen.
- **Android** — download the APK from the site, or use the web app.

Free for clients. Free for coaches during early access.
